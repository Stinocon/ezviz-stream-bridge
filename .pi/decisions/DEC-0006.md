# DEC-0006 — amends DEC-0005: the verification record, not the invariant

DEC-0005 stands exactly as written. What changes is how it is checked:

- `verify: read`, anchor `_VideoPipe` -- the class is in `ezviz_stream_bridge/session.py`
  and named by both pinning tests' subject.
- The behavioural half of the verification is the repo's gate (`.pi/verify.json`:
  pytest on everything, ruff on everything): the two tests that pin this invariant run
  with it, and the deadlock test fails on any code that parks the pump.

See DEC-0005 for the statement, the reason, and the evidence trail (the reporter's log,
the lab reproduction, the addon-image gate).
