# DEC-0007 — the session file holds the session; its pure parts have modules of their own

Where the earlier decisions say "`session.py` holds X", read it as "`session.py` uses X, and X
is defined in":

| Name | Defined in |
|---|---|
| `_MPEG_PS_DEMUXER`, `_prefix_audio`, `_audio_channels`, `_PayloadPlan`, `classify_payload` | `payload.py` |
| `_AudioPipe`, `_AUDIO_PENDING_BYTES`, `_VideoPipe`, `_VIDEO_PENDING_BYTES`, `_Sinks` | `pipes.py` |
| the RTP and MPEG-PS parameter-set caches | `parameter_cache.py` |
| the argv `_start_ffmpeg` runs | `remux.py` (`remux_argv`) |

`_decide`, `_read_prefix`, `_with_audio`, `_start_ffmpeg` and `_end_stalled_audio` did not move.
A test that patches a bound patches the module the bound lives in: `pipes._VIDEO_PENDING_BYTES`,
not `session._VIDEO_PENDING_BYTES`, which no longer exists and fails loudly if patched.
